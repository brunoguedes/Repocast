Capsule status pill — use for track status, source kind, or counts.

```jsx
<Badge tint="green" icon="check">Ready</Badge>
<Badge tint="orange" icon="hourglass">Generating</Badge>
<Badge tint="red" variant="solid">Failed</Badge>
```

- **tint**: any system color token (`blue`, `green`, `red`, …).
- **variant**: `tinted` (colored text on translucent fill) or `solid` (filled, white text).
